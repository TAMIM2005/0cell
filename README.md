# 0cell (ZeroCell) - Ultra-Lightweight Windows Native Spreadsheet

0cell is an ultra-fast, lightweight, and full-featured Windows native spreadsheet application designed with the classic Microsoft Excel aesthetic (`#107C41` Green Ribbon, Fluent interface, status bar, and formula bar).

---

## 🚀 How to Launch
You can run 0cell in any of the following ways:
1. **Direct Native App (Recommended)**: Double click **`0Cell.exe`** or **`Launch-0Cell.bat`**.
2. **Web / Browser Offline**: Double click **`index.html`** in any browser.

---

## ✨ Features Included

### 1. 🔍 Duplicate Management Suite (Full Excel Parity)
- **Highlight Duplicates**: Instantly scans the selected range and applies Excel's classic light red fill / dark red text conditional formatting.
- **Remove Duplicates Wizard**:
  - Interactive dialog to select columns to inspect.
  - "My data has headers" toggle.
  - Deletes duplicate rows and presents an exact summary: *"X duplicate value(s) found and removed; Y unique value(s) remain."*
- **Extract Unique Values**: Extracts distinct values from your selection directly into an adjacent column.
- **Clear Highlights**: Remove formatting in 1 click.

### 2. 🧮 100+ Excel Calculation & Formula Engine
- **Math & Statistics**: `SUM`, `AVERAGE`, `COUNT`, `COUNTA`, `COUNTBLANK`, `COUNTIF`, `COUNTIFS`, `SUMIF`, `SUMIFS`, `AVERAGEIF`, `MIN`, `MAX`, `PRODUCT`, `POWER`, `SQRT`, `ABS`, `ROUND`, `ROUNDUP`, `ROUNDDOWN`, `INT`, `MOD`, `MEDIAN`, `STDEV`, `LARGE`, `SMALL`, `RANK`.
- **Logical**: `IF`, `IFS`, `AND`, `OR`, `NOT`, `XOR`, `SWITCH`, `IFERROR`, `IFNA`.
- **Lookup & Reference**: `VLOOKUP`, `HLOOKUP`, `XLOOKUP`, `INDEX`, `MATCH`, `CHOOSE`, `ROWS`, `COLUMNS`.
- **Text**: `CONCAT`, `TEXTJOIN`, `LEFT`, `RIGHT`, `MID`, `LEN`, `TRIM`, `UPPER`, `LOWER`, `PROPER`, `FIND`, `SEARCH`, `REPLACE`, `SUBSTITUTE`, `TEXT`, `VALUE`.
- **Date & Time**: `TODAY`, `NOW`, `DATE`, `YEAR`, `MONTH`, `DAY`, `DATEDIF`, `DAYS`, `EDATE`.
- **Financial**: `PMT`, `PV`, `FV`, `NPV`.
- **References**: Relative (`A1`), absolute (`$A$1`, `A$1`), ranges (`A1:B10`), cross-sheet (`Sheet2!A1`).
- **Drag Auto-fill**: Dragging the fill handle adjusts relative references automatically!

### 3. 📊 Interactive Visual Charts
- Insert **Column**, **Bar**, **Line**, **Area**, and **Pie** charts.
- Draggable floating chart cards with live data binding to your grid.

### 4. 🛠️ Advanced Data Tools
- **AutoFilter**: Header filter dropdowns with search, checkboxes, and A-Z/Z-A sorting.
- **Multi-Column Custom Sort**: Sort by multiple criteria.
- **Find & Replace** (`Ctrl+F` / `Ctrl+H`): Match case, entire cell, and instant Replace All.
- **Text to Columns Wizard**: Split comma, tab, semicolon, space delimited text into columns.
- **Data Validation**: List dropdowns and value constraints.

### 5. 💾 File Formats & Excel Interoperability
- Save / Load native `.0cell` project files.
- Export to Microsoft Excel `.xls` / `.xml` format.
- Export to `.csv`.
- Print / Export to PDF.
- 2-way Clipboard TSV integration: Copy/Paste directly between 0cell, Excel, and Google Sheets!
